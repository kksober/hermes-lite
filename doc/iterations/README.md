# 产品迭代 (Iterations)

## 用途

记录每次迭代的目标、实现方案、变更清单和回顾总结。每个迭代一个文件，按日期递增。

## 内容示例

- `2026-05-01-permissions-and-sessions.md` — 交互式权限 + PTY 长命令会话
- `2026-05-15-editing-and-context.md` — 统一 diff 补丁 + ripgrep 加速搜索
- `2026-05-25-lsp-mcp-worktree.md` — LSP/MCP 客户端 + 隔离工作树执行
- `2026-05-30-smoke-test-and-stabilization.md` — CLI 全链路验证与稳定性修复

## 命名规范

- `YYYY-MM-DD-<topic-slug>.md`
- 每个迭代记录包含: 目标、涉及文件、测试增量、遇到的问题及解决方案
