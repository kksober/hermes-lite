## 各维度评分

### 读代码：A（↑ 从 A-）

| 新增能力 | 里程碑 | 说明 |
|---------|--------|------|
| AST 调用图 + 符号提取 | M13 | `ast_analysis.py` — 无外部依赖，stdlib ast |

**评价：** 工具链已经完整。AST 分析是 standout 功能——大多数 coding agent 没有这个。

---

### Skill/知识闭环：A（↑ 从 B+）

| 新增能力 | 里程碑 | 说明 |
|---------|--------|------|
| `skill_view(name)` | M12 | **Agent 现在能加载 skill 全文** |
| `skill_manage(action)` | M12 | **Agent 能创建/修补/删除 skill** |
| Agent 自省 | M14 | 每 N 轮自动提示反思、创建 skill、避免重复错误 |
| 规范引擎 | M11 | `.hermes/conventions.md` 自动发现 |

**评价：** 上一轮最大的缺口——"图书馆有目录没书"——已修复。Skill 知识闭环完成：
Agent 遇到新任务 → 加载 skill → 执行 → 如果 skill 有误 → 修补 → 如果发现新模式 → 创建新 skill。

### 写代码：A（↑ 从 A-）

| 新增能力 | 里程碑 | 说明 |
|---------|--------|------|
| 模糊匹配补丁 | M12 | 容忍尾部空格/缩进差异的 `fuzzy=True` |
| `edit_batch` 多文件编辑 | M14 | 一次操作多个文件的批量 edit |
| 编辑预览 + diff 着色 | M9 | ANSI 色彩，操作前确认 |

**评价：** 模糊匹配补丁是之前缺失的关键能力——LLM 生成的 old_text 经常有空格/缩进漂移，模糊匹配让它不再失败。

**评价：** 上一轮标明的三个高频缺失命令全部补齐。加上之前已有的流式输出、diff 着色、编辑确认、成本追踪、多项目切换，CLI 已经非常完整。

## 剩余差距（A → A+）

### 功能性
1. **浏览器工具** — 不能做 web PR review、网页交互
2. **Cron/定时任务** — 不能设定时执行
3. **多平台** — 只有 CLI + API，没有 Telegram/Discord 等

### 质量
4. **向量语义搜索** — 当前是 TF-IDF，换 embedding 模型会更准
5. **Mermaid 渲染** — 只存储不渲染
